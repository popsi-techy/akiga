Workflow template gallery uses the application-type catalog frame: a lifecycle rail, a featured from-scratch card, and a grid of template cards. Each card has Use template as a secondary button and Preview as a grey tertiary button, equal-width, so the catalog is not a grid of primary oranges. Preview still opens the flow modal; Use template names the draft and opens the builder.
