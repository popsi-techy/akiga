The connection-event Simulated reply rail leads with what IGA would extract — Message, Records, Identifier — and keeps the JSON as a labeled white payload.

Status lived in the chip, a Status row, and the payload; a second heading restated the lead; and the raw JSON was the only thing that filled the column. The chip keeps the code after a test — Sample and the lead line are gone, they only restated the title. The readout uses InfoRow. The payload stays a bordered surface block.
