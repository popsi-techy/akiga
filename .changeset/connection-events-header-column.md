The Connection Configuration header — Events, the unsaved-change count, and Save changes — now sits inside the catalog column instead of spanning the peek panel as well, so it narrows with the catalog when a slot opens. Save commits the switches in the list and nothing in the panel, so it should not hang over it; the panel gains the header's strip of height and starts level with the row that opened it.
