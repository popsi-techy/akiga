The evidence-package scope disclaimer moves from a footnote to where it is read.

It was a wall of small text below the clause table — the last thing anyone scrolls to, present only on the Coverage tab, and absent from the Seal modal and the Package history tab where the sealed artefacts it disclaims actually live. Now it is a collapsed "About this evidence" note at the top of the framework detail page (both tabs), reusing the register's Evidence-header pattern, and a concise copy rides in the Seal modal at the moment the artefact is produced. Both read from one source, `scopeOfEvidence(frameworkName)`, so the disclaimer can never be worded two ways.
