Configure on a Connection Configuration slot opens a peek panel of that event type's calls as cards — name, endpoint, connection status, attribute mapping, edit and remove — with Add event opening the event drawer. Replaces the Provisioning rules table, whose mapping column now lives on the card.

The enable switches are now staged rather than written on flip: a toolbar above the catalog counts the unsaved changes and commits them all with Save changes, or reverts them with Discard.
