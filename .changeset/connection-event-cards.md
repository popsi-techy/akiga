Configure on a Connection Configuration slot opens a peek panel of that event type's calls as cards — the call's name with its status chip, then the three things it needs (endpoint, authorization, attribute mapping) as a short icon list where a missing one turns amber, then Map attributes beside icon-only Edit and Remove. Add event opens the event drawer. Replaces the Provisioning rules table, whose mapping column now lives on the card.

The enable switches are staged rather than written on flip: an Events header above the catalog counts the unsaved changes and commits them with Save changes.
