# 09 · Competitor Research

Structured analysis of the IGA/IAM landscape — to learn proven patterns, avoid known pitfalls,
and find the gaps we can beat. One file per competitor, authored from
`_templates/competitor.template.md` and mirrored in `competitors.json`.

> **Populated (concise, by intent).** We keep **one synthesis doc** —
> [`patterns-synthesis.md`](./patterns-synthesis.md) — plus a brief `competitors.json`. Deep
> per-vendor tear-downs are intentionally out of scope (low practical value, copying risk); add a
> focused note only when a specific decision needs one, citing public sources only.
> · **Feeds:** `competitors.json`
